What leaves this browser?

Only when you click the toolbar icon: the page title, full URL (including query and fragment), and your selection or readable article. Long text is sent in numbered messages, about one per second. Oversized clips are refused, never shortened. Check for private information first.

Page access: activeTab and scripting read the current page on click, not in the background. Network access: only the Slack webhook host is requested. Messages go directly to Slack.

The secret stays in this extension’s local database, not browser sync. No clip history, analytics, or cloud extraction. Anyone with the webhook can post to its channel.
